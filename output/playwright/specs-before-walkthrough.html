01

다섯 후보가 공유할 최소 구조

처음부터 여러 부위와 모든 센서를 연결하지 않는다. 예를 들어 설문＋힘1종＋가동범위1종＋생활 동작1종을 하나의 평가 묶음으로 정한다. 하지 평가를 설명용 사례로 사용했으며, 최종 아이템을 고관절로 확정한 것은 아니다.

공통 프로그램 6개 모듈

  1. 대상·동의·권한

    기관·운영자·검토자·이용자의 역할을 구분하고 영상 저장 여부와 열람·삭제를 관리한다.

  2. 버전이 있는 평가 절차

    대상, 자세, 센서 위치, 시행 횟수, 중단·재측정 조건과 계산식을 저장한다.

  3. 측정과 품질 확인

    첫 버전은 수기·CSV 입력도 허용한다. 실시간 연결은 SDK/API 권한과 실제 출력 확인 후 추가한다.

  4. 값 계산과 비교

    힘·각도·횟수와 좌우·전후 차이를 계산하되, 비교 조건이 다르면 비교 불가로 표시한다.

  5. 검토·수정·승인

    전문가가 결과와 관리 후보를 검토하고 수정 이유와 승인 이력을 남긴다.

  6. 리포트·수행 기록·재평가

    이용자가 이해할 결과와 다음 행동을 전달하고 같은 조건으로 다시 확인한다.

초기 데이터와 기술 명세
  • 필수 저장: 익명화된 참여자 식별자, 평가일·좌우·검사자, 절차 버전, 장비·교정정보, 자세·고정·체중, 시도별 원자료/입력값, 유효 여부, 계산 버전과 검토 이력.
  • 초기 구현: 태블릿용 웹 화면＋기관 대시보드＋권한 분리 DB＋파일 저장소＋PDF/CSV 출력. 기성 장비 앱에서 확인한 값의 수기 입력부터 가능.
  • 영상: 태블릿 내장 카메라 또는 PC＋1080p30fps급 웹캠 중 한 경로. 첫 단계는 기록·전문가 확인 용도. 외부 웹캠과 iPad의 호환성을 가정하지 않는다.
  • 보안·운영: 전송·저장 보호, 기관 간 데이터 분리, 백업·복구, 수정 이력과 보유기간. 기업에는 개인 결과와 기관용 집계 결과를 분리한다.

평가 묶음의 순서·피로·검사시간과 임상적 유용성은 개별 검사 문헌과 별도로 확인해야 한다.[14][15]

공통 개발비의 근거

공통 프로그램 직접인건비는 약2,351만~3,788만원이다. 아래 작업량 가정에 2026년 공식 직무별 평균임금을 곱했다. 1인월은 한 사람이 한 달 동안 투입되는 작업량이며 전체 달력 기간과 같지 않다.[1]

02 · 후보 A

기능평가 키트

휴대 장비와 표준 절차를 묶어, 기관에서 같은 조건의 평가·설명·재평가를 운영하는 형태다.

대략적인 구성

  • 태블릿1대 또는 기존 노트북, 힘 센서1개, 각도계/IMU1종, 고정 벨트·패드·휴대 케이스.
  • 평가 안내 화면, 수기/CSV 결과 입력, 시도별 품질 표시, 좌우·전후 리포트.
  • 첫 평가 범위는 힘1종·ROM1종·기능 과제1종. 카메라 AI 자동 판정은 후속 검증 항목.

결과가 나오는 과정

  1. 운영자가 평가 묶음을 선택

    문진과 목표를 확인하고 허용된 절차를 고른다. 임상 해석이 필요한 경우 담당 전문가가 선택한다.

  2. 자세·벨트·센서 위치를 설정

    영점과 좌우를 확인하고 위치를 기록한다. 화면 안내만으로 설정이 끝났다고 가정하지 않는다.

  3. 시도별 측정과 유효성 확인

    힘N·각도°·횟수 등을 기록한다. 이탈·포화·중단·자세 실패는 무효/재측정으로 처리한다.

  4. 리포트 초안과 관리 연결

    유효값과 비교 조건을 요약하고, 검토자가 해석·운동 후보·재평가 계획을 확정한다.

초도 장비 가정 350만~600만원/1세트. 자체 SW MVP 예산은 공통 개발을 포함해 3,900~7,400만원, 일정은 8~12주 가정이다.

장비 가격 예시와 연동 조건

Lafayette 01165APP의 공개가격은 USD1,800이다. 계획 환율 USD1=1,500원으로 계산하면 270만원이며 배송·세금·앱의 상업적 연동 조건은 별도다. 공식 한국 iPad 표시가749,000원을 함께 쓰면 공개가격 소계는 약344.9만원이다. 벨트·패드·각도계·케이스·예비품은 여기에 추가된다.[2][3]

Lafayette 앱 사용권과 자체 앱의 실시간 stream 권한은 같지 않다. API가 미확인이라면 수기/파일 입력으로 먼저 운영하고, 실시간 연동을 약속하기 전에 계약을 확인한다. VALD도 구독·조직권한·승인이 필요하고 결과 API를 실시간 센서 SDK로 간주할 수 없다.[10]

힘의 최대·안정구간을 다루는 다음 단계에서는 100~200Hz급 원시 수집을 시작안으로 검토할 수 있다. 실제 기기의 출력 모드를 확인하며, 초기 RFD 같은 순간적 지표는 별도 시간해상도·기준 장비 검증 전에는 추가하지 않는다.

독자 기기로 발전하려면

반복적으로 나타나는 고정 실패·장비 호환·조작 부담이 현재 제품으로 해결되지 않는지 확인한다. 자체 BLE 힘 모듈을 만들면 로드셀·증폭/ADC·무선·전원·외장·펌웨어·교정 도구가 추가된다. 아래 비용 장에서 이를 별도 확장으로 다룬다.

첫 실험의 성공 조건

다른 평가자도 같은 조건으로 유효한 데이터를 얻고, 결과가 실제 운동 계획이나 재평가에 사용되는지 확인한다. 리포트가 출력된다는 것만으로 충분하지 않다.

03 · 후보 B

가이드형 측정 스테이션

키트에서 매번 손으로 잡고 맞추던 조건을 의자·프레임·고정 센서로 재현하는 형태다.

대략적인 구성

  • 처음에는 한두 자세만 지원하는 수동 조절식 의자/벤치·프레임·고정 패드·센서1~2개.
  • 좌석·패드 위치 눈금과 잠금, 체형별 설정 기록, 신속한 해제 장치, 직원 호출/중단 입력.
  • 가이드 화면＋설정 체크리스트＋측정 시작/재측정＋비교 리포트. 전동 구동·전신 자동 세팅은 기본 범위에서 제외.

결과가 나오는 과정

  1. 대상에 맞춰 위치를 설정

    직원이 체형·검사 자세에 맞춰 의자·패드·벨트를 조절하고 설정값을 저장한다.

  2. 고정·영점·자세 확인

    기본형은 직원이 체크한다. 별도 접촉/위치 센서를 설치하기 전에는 자세를 자동 확인했다고 표시하지 않는다.

  3. 화면 안내에 따라 힘을 측정

    승인된 절차의 시도와 휴식을 진행하고 무효·중단을 기록한다.

  4. 저장된 세팅으로 재평가

    같은 설정을 복원하고 조건 변경을 표시한다. 이후 해석·관리 연결은 공통 검토 흐름을 따른다.

초도 장비·기구 가정 800만~1,800만원/1대. 기구 설계·시제품 인건비를 포함한 자체 SW MVP 예산은 5,900~13,800만원, 일정은 12~20주 가정이다.

기구·센서·출력의 설계 조건

초기 센서 범위는 실제 과제의 최대 힘과 과부하 여유로 정한다. 500~1,000N급 등을 후보로 검토하더라도 모든 대상에게 충분한 범위로 확정하지 않는다. 영점·선형성·히스테리시스·드리프트·고정 변형을 벤치에서 확인한다.

패드 위치와 힘 방향이 바뀌면 같은 센서 힘도 해석이 달라진다. 힘N을 기본 출력으로 하고, 수직 모멘트암을 측정한 경우에만 토크Nm를 계산한다. 단순 거리만 입력해 자동 토크를 보장하지 않는다.

기성품을 쓰는 참고 경로로 Lafayette 01165APP USD1,800＋stand USD2,550의 소계는 USD4,350, 계획 환율로 약652.5만원이다. 이는 태블릿·의자·벨트·안전 보완·설치·개발비가 없는 부품 가격 합이다.[2]

키트보다 나아야 하는 점

측정 오차뿐 아니라 세팅 실패율·재측정·직원 개입·전체 소요시간이 줄어드는지 비교한다. 장비가 커졌지만 직원이 더 오래 붙어 있어야 한다면 스테이션의 가치는 약해진다.

04 · 후보 C

병원용 평가·관리 보조 시스템

새 센서보다 평가 선택·기록·설명·추적을 하나의 과정으로 연결하는 데 초점을 둔다.

대략적인 구성

  • 환자 문진 화면, 의사/담당 전문가의 검사 선택 화면, 직원용 측정 화면.
  • 기존 장비의 수기·CSV 입력, 결과 초안, 수정·승인 이력, 환자 리포트와 재평가 목록.
  • 초기에는 병원의 기존 장비와 단말을 사용하고 외부 EMR 자동 연동은 넣지 않는다. 자료 내보내기/첨부 방식부터 검토한다.

결과가 나오는 과정

  1. 문진으로 진료 전 정보를 모은다

    증상·생활 제한·이전 관리·목표를 구조화해 누락과 추가 확인 응답을 표시한다.

  2. 의사/담당 전문가가 검사를 선택한다

    시스템이 모든 검사를 자동 배정하지 않는다. 대상·목적과 보류 조건을 확인한다.

  3. 직원이 측정하고 시스템이 정리한다

    세팅·검사·QC 후 유효한 값, 증상 반응, 비교 가능 여부와 결과 초안을 만든다.

  4. 전문가가 검토·수정·승인한다

    병력·진찰·다른 검사와 함께 해석하고 필요한 관리·운동·추가 평가를 결정한다.

  5. 설명·수행·재평가로 연결한다

    사용자가 이해할 계획과 다음 시점을 전달한다. 악화·미개선·미수행은 검토 목록으로 되돌린다.

기존 병원 장비 사용 시 추가 단말 가정 50만~150만원. 자체 SW MVP 예산 5,000~9,600만원, 일정10~16주 가정이다. EMR 실연동은 별도다.

업무·운동 선택·기관 연동 범위

운동 라이브러리에는 목적·대상·주의·난이도·진행·중단 조건과 전문가 검토 버전을 둔다. 시스템은 확인된 기능 과제·목표·증상·기존 계획으로 승인된 후보를 검색한다. 담당 전문가가 운동과 강도·빈도·재평가를 확정한다.

LLM을 사용하더라도 승인된 구조화 정보의 문장 초안에 제한하고, 원자료·불확실성·검토자 결정을 보존한다. 자동 원인 판정이나 자유 생성 운동 처방을 기본 기능으로 두지 않는다.

EMR 연동은 병원·공급사 API, 사용자 매핑, 기록 권한, 보안검토, 장애 책임에 따라 달라진다. 본 예산에 포함하지 않았고 별도 견적이 필요하다. 기관 양식 맞춤과 기본 권한·감사이력은 MVP에 포함한 가정이다.

인력 보완 효과를 계산하는 방법

초기 시간 가정은 세팅5~10분＋측정10~20분＋검토·설명5~10분＋정리3~5분이다. 표준 소요시간이 아니라 파일럿에서 검증할 입력값이다. 의사 검토시간을0으로 놓고 절감 효과를 계산하지 않는다.[18]

준비·중복 입력·수정·재측정까지 합친 총시간과 판단에 실제 쓰인 정보를 비교한다. 검토자가 보고서를 다시 작성한다면 자동화의 추가 가치가 작을 수 있다.

05 · 후보 D

운동 피드백 시스템

특정 운동을 할 때 근육 전기활동과 움직임을 보여주고, 전문가가 정한 수행 목표를 학습하도록 돕는다.

대략적인 구성

  • 처음에는 표면근전도2채널＋IMU1~2개＋노트북/지원 단말＋부착·충전·동기화 구성품.
  • 전극 배치 안내, 신호 품질 확인, 참조 과제, 실시간 그래프·반복 구간 기록.
  • 한 운동·한 피드백 목표부터 시작한다. 신호 진폭을 근력·정상 점수·원인 근육으로 표시하지 않는다.

결과가 나오는 과정

  1. 전문가가 과제와 목표를 정한다

    무엇을 학습시키려는지, 피드백 없이도 어떻게 성공을 확인할지 정한다.

  2. 부착·보정·참조 측정

    전극 위치·피부 준비·센서 방향을 기록하고 잡음·포화·이탈을 확인한다.

  3. 신호를 처리하고 피드백한다

    검증한 필터·RMS·동작 구간으로 특징값을 계산한다. 정규화 참조와 장비 모드를 함께 표시한다.

  4. 운동 수행과 학습을 다시 본다

    화면의 신호가 커졌는지보다 의도한 동작과 과제 수행이 좋아졌는지, 피드백을 끈 뒤에도 유지되는지 확인한다.

연구용 기성 구성의 초도 장비 가정 300만~900만원. 자체 SW MVP 예산 5,300~10,300만원, 일정10~16주 가정이다. Delsys/Noraxon 구매 견적을 대신하는 범위는 아니다.

샘플링·신호 처리·정규화 사양
  • sEMG 시작안: 2~4채널, raw 약2kHz, 예를 들어20~450Hz 대역. 실제 모델·모드·하드웨어 필터를 확인한다. 이중 필터 여부를 기록한다.
  • 특징값 시작안: RMS100ms 창. 창 길이·갱신주기·지연을 따로 기록한다. 이 값들은 보편 표준이 아니라 검증 시작안이다.
  • IMU 시작안: 50~100Hz급, 부착·기준 자세·좌표계·드리프트·자기장 영향을 확인한다.
  • 동기화: 타임스탬프·시계 드리프트·손실을 측정한다. 화면에 함께 보인다고 동기화됐다고 하지 않는다.
  • 정규화: 적합하면 MVC, 그렇지 않으면 정한 하위최대 참조 과제를 쓴다. ‘참조 과제 대비 값’과 ‘최대근력의 비율’을 혼용하지 않는다.
  • 품질: 전극·피부·인접 신호·전원 잡음·동작 아티팩트를 점검하고 실패하면 점수·피드백을 보류한다.

Delsys 등의 실제 모드와 지원 장비를 확인해야 하며, API 라이선스는 일반 분석 소프트웨어와 별도일 수 있다.[12][13][16][17]

공개가격으로 볼 수 있는 하한과 빠진 비용

Shimmer EMG 개발 키트의 최저 표시€799＋ConsensysPRO1PC1년€199를 단순 합하면€998이다. 계획 환율€1=1,650원 기준 약164.7만원이지만, 최저 옵션 센서 수·dock·구성 확인 전 확정 견적으로 사용할 수 없다.[7][8]

IMU 단품€430이나 EMG 단품€680만 더해 첫 구매의 완성 시스템 가격을 계산하면 안 된다. 첫 구매 개발 키트, 호스트PC, 동기화·부착·소모품·개발·계약 비용을 확인한다.[5][6][9]

연구용 구성의 사용 가능성이 기관 배포·의료 목적 사용·상업적 재판매를 자동 보장하지 않는다. Delsys·Noraxon 등 전문 시스템은 센서 수·base·SW·API를 나눠 견적받아야 한다.

06 · 후보 E

정기 기능평가 서비스

기관이 장비를 구매하는 대신 평가 운영·결과 설명·재평가를 서비스로 이용한다. 자체 기기가 없어도 시작할 수 있다.

대략적인 구성

  • 2개 동선이라면 휴대 키트2세트, 예약·동의·평가·품질 검수·리포트 절차.
  • 운영자2명, 측정 품질·일반 리포트 검수 담당. 의료적 평가·처방을 제공하는 경우 인력·장소·운영 모델을 별도로 정한다.
  • 기업·운동기관의 일반 기능 기록 서비스와 병원 임상 평가는 별도 제공 범위로 설계한다.

결과가 나오는 과정

  1. 기관과 제공 범위를 합의한다

    목적·대상·검사 묶음·일정·개인 결과와 기관용 집계 범위를 정한다.

  2. 사전 문진과 현장 평가

    동의·측정 가능 여부를 확인하고 같은 절차로 기록한다.

  3. 검수·설명·다음 행동

    무효·누락·이상 응답을 검토하고 확인한 기능과 허용된 관리 정보를 전달한다. 필요한 임상 판단은 적절한 전문가 경로로 연결한다.

  4. 재평가와 기관 재계약

    동일 조건의 재측정·관리 수행을 확인한다. 행사 참여자 수뿐 아니라 실제 이용과 기관의 재도입을 본다.

수기·기성 도구로 운영하는 신규 구매 초기 실험비는1,300만~2,500만원 가정. 키트2세트와 운영준비·첫 소규모 시행을 포함한 현금 예산이다. 자체 SW를 만들면 공통 개발 포함 4,600~8,100만원, 8~12주 가정이다.

기존 기관 장비를 쓰거나 대여한다면 초도 구매비를 줄일 수 있다. 대여료와 협업 조건은 확인 전이므로 임의의 절감액을 확정하지 않았다.

최종 결과는 어떤 모습인가?

보고서는 측정한 사실, 계산한 정보, 해석, 다음 행동을 분리한다. 아래는 데이터 형식을 보여주는 가상 예시이며 사용자 개인의 실제 결과가 아니다.

가상 리포트 예시 · 진단 결과 아님

오늘의 고관절 외전 과제

측정한 사실
정한 자세·고정 조건에서 유효 시도를 기록. 오른쪽180N, 왼쪽210N. 적용한 시도 선택 규칙과 중단·증상 정보를 함께 표시.
계산한 정보
좌우 차이14.3%: (큰 값−작은 값)/큰 값×100. 이 비율은 차이의 표현이며 자동 비정상·원인 판정이 아니다.
비교 가능 여부
검사자·자세·고정·절차가 이전과 다른 경우 비교 제한. 자체 검증된 오차 기준이 없으면 ‘확실한 개선’으로 표시하지 않는다.
전문가 검토
증상·목표 활동·신경학적 소견·다른 검사와 함께 결과를 검토. 검토자와 승인 일자를 표시.
다음 행동
전문가가 승인한 운동/일반 관리 안내 또는 추가 평가 경로, 수행 기록과 재평가 시점. 의료와 일반 운동의 역할을 구분.

판정 규칙은 무엇으로 구성하나?

  • 측정 실패: 센서 이탈·포화·자세 실패는 ‘측정 불가’다. 0점이나 정상으로 처리하지 않는다.
  • 낮은 값: 어떤 과제에서 어떤 조건의 값인지 표시한다. 근육군 기능 소견과 통증의 원인 주장을 분리한다.
  • 전후 변화: 해당 절차·집단에서 검증한 측정오차와 함께 판단한다. MDC를 정상·위험·중요한 개선의 기준으로 바꾸지 않는다.
  • 예외: 새 증상·불편감 증가·수행 불안 등의 응답은 일시정지·검토로 돌린다. 자동 강도 상승을 막는다.
단위와 비교 규칙

힘은N, 수직 모멘트암을 측정한 토크는N·m다. 체중 정규화 힘N/kg와 토크N·m/kg를 혼용하지 않는다. kgf는 질량kg과 다르므로 장비 단위·변환을 보존한다.

피크와 안정구간 평균, 시도별 최대와 시도들의 평균은 서로 다른 산출값이다. 검사 버전에 계산 규칙을 저장한다. MDC는 해당 검사자·반복·시점·오차모형을 포함한 검증 결과로 정하고 기존 연구의22~35%를 새 기기의 고정 기준으로 복사하지 않는다.[14]

월 운영비의 시작 가정

초기1~3기관의 작은 서비스에서 서버·저장·백업10만~50만원/월, 유지보수·문의 대응40만~150만원/월을 별도 가정할 수 있다. 이는 공급사 견적이 아니다. 기관 직원·의료진의 평가·검토 노동, 장비 구독/API·소모품·출장은 별도다. 보안·이용량·영상 저장·기관 지원 요구에 따라 다시 계산한다.

독자 힘 센서 모듈을 만들 때의 추가 범위

기성 센서를 바꾸어 자체 BLE 힘 모듈을 개발한다면 로드셀·아날로그/ADC·무선·배터리/충전·외장·펌웨어·교정 도구를 설계한다. 2~4인월×월600만~900만원＋시제품·부품200만~600만원＋벤치 검증300만~800만원이라는 가정은 예비비20% 포함 약2,000만~6,000만원의 추가 탐색 범위다.

확정 견적이 아니며 기성품을 대체해 줄어드는 구매비를 정산해야 한다. 무선·전기안전·정식 인허가·양산은 제외했다. 이 범위를 자체 sEMG 아날로그 회로 개발비로 그대로 사용하지 않는다.

정식 판매 준비는 별도 예산이다. 사용목적과 분류에 따른 시험·품질체계·기술문서·허가, 해당 시 임상 연구·IRB·통계, 양산 설계·금형·생산검사·AS를 이 시제품 예산으로 충당한다고 가정하지 않는다. 제품이 정해지지 않아 총액을 제시하지 않았다.[19][20]

공개가격과 원화 예산의 관계

계산 편의를 위해USD1=1,500원, EUR1=1,650원을 계획 환율로 사용했다. 실시간 시세가 아니다. 외화 결제액의 환율이±10% 변하면 그 외화 부품 부분도±10% 변한다. 전체 개발비가 같은 비율로 변하는 것은 아니다.

공개 소매가는 판매자가 표시한 세금 조건 그대로 인용했다. 원가 모델은 세금·수입정산을 별도 확인하는 예산이며 기존 소매가에 VAT를 무조건 다시 더하지 않는다. 구매 시 배송·관세·VAT·지원·구독·교정·상업적 사용권을 포함한 총액을 다시 확인해야 한다.

린 프로젝트에서 만들 범위

본격 자체 SW MVP의8~20주 일정과, 몇 주 안에 하는 수요·운영 검증은 구분한다. 초기에는 기존 장비로 평가 과정을 운영하고 결과가 다음 행동에 쓰이는지부터 확인할 수 있다.

  1. 평가1묶음·기관1곳·대상1유형을 정한다

    사용목적·실제 담당자·결과를 보고 바뀔 결정을 정의한다. 구매·대여·협력 장비와 데이터 추출 권한을 확인한다.

  2. 수기/기성 도구로 소규모 운영한다

    평가자·세팅·실패·검토·설명 시간을 기록하고 표준 절차를 수정한다. 운영·연구에 필요한 동의와 기관 절차를 확인한다.

  3. 반복 측정과 결과 활용을 본다

    재부착·다른 검사자의 차이, 이용자의 이해, 실제 운동·관리 계획에 사용한 정보를 확인한다. 짧은 파일럿으로 장기 치료 효과를 주장하지 않는다.

  4. 관찰한 공백에만 개발한다

    세팅이 문제면 스테이션, 기록·승인·추적이 문제면 병원 보조, 수행 학습이 문제면 피드백을 추가한다. 새 센서가 필요한지 따로 판단한다.

합격 기준은 목적에서 역으로 정한다

벤치 정확도·드리프트, 검사자/날짜 간 오차, 실패율과 총업무시간, 결과 이해·관리 활용을 분리한다. 지금 ‘정확도95%’ 같은 하나의 숫자를 정하지 않는다. 필요한 최소 변화와 실제 의사결정에 맞춰 사전 기준을 세운다.

현재 가장 작은 출발점은 휴대 키트＋정기 평가 운영 또는 기존 병원 장비＋결과 정리·검토다. 이는 우선 학습 경로이며 최종 제품을 확정한 결론은 아니다.
