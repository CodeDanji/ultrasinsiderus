# 초음파 · 스파 신체 시각화 프로젝트

초음파 사업·기술 조사부터 스파 카메라 촬영, 사진 처리, 내부 모형 이미지·3D 생성 파이프라인 설계까지 모은 독립 저장소다. `CodeDanji/insiders-project`의 관련 자료를 2026-11-06 기준으로 분리했다.

## 실행 코드와 모델 자산

실행 구현은 [`runtime/`](./runtime/README.md)에 있다. 이전 문서 추출에는 로컬의 미커밋 실행 코드가 누락됐으며, 이번 변경에서 코드·환경 설정·분할 가중치·3D 자산을 함께 추가했다.

- Python 3.12 / Blender 4.3.2, CPU 실행. Linux 새 가상환경에서 검증하고 Windows 설정 명령을 제공한다.
- `runtime/assets/weights/u2netp.onnx`: 사전학습 분할 가중치. `ecorche.glb`, `vessels.glb`: 실제 사용하는 3D 원본 자산.
- [`runtime/assets/manifest.json`](./runtime/assets/manifest.json): 원출처·라이선스·SHA-256.
- 사진 → 분할 → 표준 모형 정렬 → 동일 GLB의 Blender 렌더 → 사진 합성을 구현한다. 개인 내부 복원·4카메라·굴절 보정을 구현했다는 뜻은 아니다.
- 개인 사진은 포함하지 않는다. 샘플은 합성 족욕기 사진이다.

```sh
cd runtime
bash setup.sh
.venv/bin/python run.py sample
.venv/bin/python app.py
```

Windows 명령과 수동 마스크·기준점 재현 옵션은 [실행 안내](./runtime/README.md)를 따른다.

## 포함 자료

| 위치 | 내용 |
|---|---|
| `초음파_*.md` | 활용 영역, 기기·시장, 근골격계 회복 추적, 360도 단층촬영 조사 |
| `스파_*.md` | 현행 PRD, 기기·오픈소스, 프로젝트 맥락 |
| `outputs/research_*.md`, `outputs/스파_*.md` | 촬영·표시, 표면 3D, 내부 해부학 자산, 생성 기술 세부 조사 |
| `outputs/*.html`, `output/playwright/` | 관련 보고서, 제품 참고 이미지가 포함된 HTML, PNG 화면 캡처, PDF, 보고서 작성·검사 스크립트 |
| `outputs/backups/` | 보고서 수정 전 사본 |
| `archives/` | 현행 PRD로 대체된 과거 모델·필터 결정 문서 |
| `migration/manifest.json` | 원본 경로, 출처 커밋, 파일별 용량·SHA-256 |

초음파 조사에서 파생된 근골격계 기능평가·B2B2C 비교 보고서는 **과거 대안 조사**로 보존했다. 현재 제품 사양은 PRD를 따른다. 일반 세션 안내, 밸랩·십만플, 자기소개 자료는 제외했다. 기존 상대경로와 파일 내용은 보존하되, 제외한 세션 안내 링크 1개는 원본 저장소의 고정 커밋 URL로 변경했다.

## 현재 상태

- 보관된 이미지는 보고서 화면 캡처와 보고서 안의 참고 이미지다. 실제 이용자의 다중 카메라 촬영 원본·기준 이미지 세트는 현재 클라우드 작업공간에서 확인되지 않았다.
- `runtime/`에는 단일 사진 기반 시뮬레이션 실행 코드·가중치·메시가 있다. PRD의 전체 장치·자동화·품질 검증 완료와는 구분한다.
- `output/playwright/`의 코드는 보고서 작성·검사용이며 사진→3D 추론 코드가 아니다. 해당 스크립트는 과거 작업 기록이므로 실행 시 보고서를 덮어쓸 수 있고 일부는 외부 자원을 가져온다.
- RGB 사진 기반 내부 시각화는 실제 초음파 내부 측정 결과가 아닌 일반 해부학 기반 시뮬레이션이다.

## 열람

Markdown 문서는 GitHub 또는 편집기로 열고, `outputs/*.html`은 브라우저로 연다. 화면 캡처는 `output/playwright/*.png`에서 확인한다. 사진 파이프라인 실행은 `runtime/README.md`를 따른다.

문서에 인용된 외부 코드·모델·이미지·해부학 자산의 이용조건은 각 원출처를 따른다. 이 저장소를 분리하면서 외부 자산에 새 라이선스를 부여하지 않았다.
