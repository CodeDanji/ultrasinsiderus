# 스파 신체 시각화·3D 생성 오픈소스 조사

조사 기준일: 2026-10-30. 목적: 고정 카메라 여러 대가 있는 족욕기 규모의 스파 장치에서, 개인 사진과 연결된 외형·뼈·근육 등의 시각화 경험을 만드는 후보 선정.

## 먼저 읽을 판단

**구현 후보는 충분하다. 다만 ‘사진 → 개인의 실제 내부·체성분 → 완성된 3D’를 한 번에 해결하는 검증된 범용 오픈소스는 이번 조사에서 확인하지 못했다.** 가장 구체적인 경로는 사진에서 외형을 얻거나 생성하고, 별도의 해부학 자산을 맞춘 뒤, 레이어와 단면을 조작하는 화면으로 전달하는 것이다.

브랜딩에 필요한 시각적 완성도는 생성 모델 하나의 품질 외에도 해부학 자산 정리·재질·조명·애니메이션·화면 구성에 좌우된다. 아래 우선순위는 실제 발/하퇴 사진으로 실행 비교하기 전의 선정 의견이다.

‘뼈 이상’은 뼈뿐 아니라 근육·힘줄·지방 등 더 많은 구조를 뜻하는 것으로 해석했다. 병변이나 이상 소견을 만들라는 요청으로 해석하지 않았다.

## 1. 해결해야 할 일을 나누기

| 단계 | 원하는 결과 | 적합한 도구 유형 | 중요한 구분 |
|---|---|---|---|
| 촬영 | 여러 방향에서 초점이 맞는 개인 사진 | OpenCV, 보정 도구 | 비싼 카메라보다 입력에 맞는 초점·조명·배치부터 확인 |
| 전처리 | 통·배경을 뺀 발/다리 이미지 | SAM 2, 배경 제거, 마스크 편집 | SAM의 물체 마스크가 근육·뼈의 분할인 것은 아님 |
| 외형 | 회전 가능한 개인과 닮은 표면 | 생성형 3D 또는 다중 시점 복원 | 생성은 보이지 않는 면을 채우므로 관측과 동일하지 않음 |
| 내부 | 뼈·근육 등 레이어 | BodyParts3D 등 해부학 자산, 모델 피팅 | 표준 모델을 맞추는 것과 실제 내부 촬영은 다름 |
| 표현 | 회전·확대·투명도·단면·설명 | Blender, Three.js 등 | 화면의 완성도와 내부 정보의 정확도는 별도 |
| 정량 데이터 | 체지방률·골격근량·상태 추적 | 별도 검증된 측정/추정 경로 | 아름다운 생성 이미지에서 건강 수치를 계산했다고 볼 수 없음 |

## 2. 지금 비교할 세 가지 경로

### A. 해부학 자산 중심 — 첫 체험 시연 우선 후보

사진에서 윤곽·방향·대략적인 크기를 얻고, 해당 부위의 표준 뼈·근육 모델을 맞춘다. Blender에서 정리한 모델을 GLB 등으로 내보내 Three.js 화면에서 레이어를 전환한다.

- 장점: 구조와 명칭을 통제하기 쉽고, 현장에서 매번 무거운 생성 모델을 돌리지 않아도 된다.
- 부담: 개인 외형과 해부학 자산을 맞추는 작업은 자동으로 해결되지 않는다. 첫 버전은 수작업 확인이 필요할 수 있다.
- 얻는 경험: ‘내 사진과 연결된 신체 구조 탐색’. 개인의 실제 근육량·뼈 상태를 측정했다는 근거는 제공하지 않는다.
- 자산 우선 후보: [BodyParts3D 아카이브](https://dbarchive.biosciencedbc.jp/jp/bodyparts3d/desc.html). [2025-02-27 갱신 이용허락](https://dbarchive.biosciencedbc.jp/jp/bodyparts3d/lic.html)은 CC BY 4.0. 구 프로젝트 페이지의 BY-SA 표기가 남아 있으므로, 사용한 파일 출처·버전·해당 허락을 함께 보관한다. Z-Anatomy 같은 파생 배포물의 조건은 자동으로 동일해지지 않는다.

### B. 생성형 외형 3D + 해부학 자산 — 생성 가능성 비교 후보

[TripoSR](https://github.com/VAST-AI-Research/TripoSR)와 [TRELLIS](https://github.com/microsoft/TRELLIS)를 같은 사진으로 비교한다. 외형 생성 후 내부는 A와 같이 별도로 구성한다.

- TripoSR: 단일 이미지 기반, 코드·사전학습 모델 MIT. 기본 추론 약 6GB VRAM이라는 공식 안내. 낮은 진입 부담의 기준선 후보다. 사진 여러 개를 나열하는 배치 실행을 다중 시점 결합으로 혼동하지 않는다.
- TRELLIS: 이미지 조건 3D 자산 생성, 여러 이미지 조건 예제가 있다. 공식 요구는 NVIDIA 16GB 이상, Linux 검증 중심. 다중 이미지 경로는 별도 다중시점 전용 학습 모델이 아닌 기법이어서 모든 입력에서 품질이 보장되지 않는다. 본체·모델 MIT와 별개인 렌더링 서브모듈 조건을 확인한다.
- 두 모델 모두 사람의 발가락·발목·좌우·비율 보존은 실제 입력으로 시험해야 한다. 여러 방향에서 그럴듯해 보이는 결과가 해부학적 정확성을 보장하지 않는다.

### C. 다중 시점 외형 복원 + 해부학 자산 — 개인 외형 유사성 우선 후보

고정 카메라를 보정한 뒤 사진 간 대응으로 표면을 재구성한다. 생성형 도구가 원본과 다른 발을 만들 경우 비교할 경로다.

- 후보: COLMAP/OpenMVS, Meshroom, VGGT 계열 등. 세부 조건은 아래 전문 조사에 정리한다.
- 장점: 관측한 사진과 외형의 연결을 더 직접적으로 평가할 수 있다.
- 부담: 단색 피부·젖은 표면 반사·통의 가림·촬영 중 움직임·물 경계가 어렵다. 내부 자산을 맞추는 작업은 여전히 별도다.
- 카메라를 고정하면 보정값을 재사용할 여지가 있지만, 장치가 움직이거나 초점·광학 조건이 바뀌면 다시 검증해야 한다.

## 3. 주요 도구를 한눈에 비교

아래는 문서상 역할과 채택 우선순위다. 라이선스가 있는 공개 모델을 모두 엄격한 의미의 오픈소스로 간주하지 않는다. 코드·가중치·자산·의존성을 나눠 확인했으며 정확한 원문 링크·환경·출력은 각 상세 보고서에 있다.

| 도구/모델 | 우리 프로젝트에 쓰는 부분 | 현재 판단 |
|---|---|---|
| OpenCV / Caliscope | 고정 카메라 촬영과 보정 | 기반 후보. 카메라 자체의 동시 연결은 실물 검증 필요 |
| SAM 2 | 사진에서 발·다리 외곽 마스크 | 전처리 후보. 내부 장기 분할 기능 아님 |
| Depth Anything V2 Small | 사진에서 외부 깊이 조건 | 전처리 후보. Small과 큰 모델의 라이선스 다름 |
| TripoSR | 1장 → 회전 가능한 외형 메시 | 빠른 생성 기준선. MIT 코드·모델, 약 6GB 공식 안내 |
| Stable Fast 3D | 1장 → UV·재질 포함 GLB | 재질 마감 비교. 약 6GB, Windows 실험 지원. 상업 등록·매출 조건 있음 |
| TRELLIS | 이미지 → mesh/Gaussian, 선택 다중 이미지 조건 | 16GB 이상 Linux 중심. 주 코드/모델 MIT지만 NC 서브모듈이 있어 전체 파이프라인 상업 채택 보류 |
| TRELLIS.2 | 1장 → PBR 재질 3D | 높은 시각 품질 비교 후보. 주 코드·모델 MIT, 24GB 이상 Linux 검증. 의존성 별도 |
| COLMAP | 여러 사진 → 카메라·점군·표면 | 관측한 외형 복원의 기준선. 겹침·피부 특징점 부족을 시험해야 함 |

| OpenMVS | 카메라/점군 → 텍스처 표면 | AGPL과 포함된 제3자 연구용 코드까지 검토 전 제품 편입 보류 |
| VGGT-1B-Commercial | 여러 시점 → 깊이·카메라·점군 | 적은 뷰 복원 비교. Commercial 체크포인트 지정, 게이트·사용조건 확인 |
| DUSt3R / MASt3R / VGGT-Ω | 학습 기반 다중 시점 구조 | 연구 비교 후보. 비상업 조건으로 유료·브랜드 운영 기본 후보에서 제외 |
| Hunyuan3D-2 / 2.1 | 이미지 → 형상·텍스처 | 한국이 라이선스 적용 지역에서 제외. 한국에서 쓸 별도 권한 없으면 채택 보류 |
| BodyParts3D | 뼈·근육 등 분리 해부학 OBJ | 내부 레이어 원천 1순위. 최신 아카이브 BY 4.0·버전·크레딧 확인 |
| Z-Anatomy | 보기 좋게 구성된 해부학 묶음 | 편리하지만 NC 혼합 자산과 BY-SA 확인. 통째 상업 승인하지 않음 |
| MakeHuman / MPFB | 표준 외피·아바타 | core asset CC0. 사진 자동 피팅이나 내부 측정은 아님 |

| SUPR-Foot | 발가락·접촉 변형 포함 발 외형 | 발 전용 연구 후보. 비상업이며 내부 아틀라스 아님 |

| ComfyUI / diffusers | 2D 조건부 생성 시안 / 자동화 | 이미지 표현 비교에 적합. 엔진과 사용할 모델의 조건은 별도 |
| ControlNet / SDXL | 윤곽·깊이에 맞는 합성 이미지 | 스타일 시안 후보. 2D 여러 장을 독립 생성해도 일관된 내부 3D가 되지 않음 |
| FLUX.1 Depth dev | 깊이 조건 고품질 2D 생성 | dev weights 비상업. 생성물의 상업 사용과 상업 서비스에서 모델 실행은 다른 권리 |
| TotalSegmentator / MONAI / 3D Slicer | 의료영상 분할·검토·모델화 | 실제 CT/MRI가 필요한 경로. RGB-only 내부 생성 엔진으로 제외 |
| MAISI / X2CT | 가상 CT 생성 / X-ray→CT 연구 | 개인 RGB 내부 측정과 다름. MAISI 가중치 비상업, X2CT는 X-ray 필수 |

### 특히 잘못 선택하기 쉬운 조건

- [TRELLIS의 diffoctreerast](https://github.com/JeffreyXiang/diffoctreerast/blob/master/LICENSE)는 비상업 연구·평가 제한이다. 메인 저장소 MIT 배지만으로 모든 설치 경로를 승인하지 않는다.
- [Hunyuan3D-2 라이선스](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/blob/main/LICENSE)는 South Korea를 적용 지역에서 제외한다고 명시한다. 단순히 학생 실험이면 해결되는 조건이라고 보지 않는다.
- [VGGT Commercial](https://huggingface.co/facebook/VGGT-1B-Commercial)은 별도 체크포인트다. 원본·Omega를 같은 권리로 취급하지 않는다.
- [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2)의 Small 가중치는 Apache-2.0이지만 Base/Large/Giant는 CC BY-NC 4.0이다.
- [BodyParts3D 최신 아카이브 허락](https://dbarchive.biosciencedbc.jp/jp/bodyparts3d/lic.html)을 다른 사이트의 파생 atlas 전체에 적용하지 않는다.

### 뼈보다 더 많은 구조는 어디까지 가능한가?

뼈 외에 근육·힘줄·혈관·신경을 분리한 참조 해부학 자산을 화면에 배치하는 후보가 있다. 다만 **사용할 부위의 실제 파일 목록과 품질을 아직 다운로드 검증하지 않았다.** 특히 피하지방층의 완전성과 개인화는 별도다. 발/하퇴 사진에서 복부 장기를 개인화하는 것은 입력 범위와 맞지 않는다.

표면 기하에서 합성 X-ray를 예측하는 [CVPR 2018 연구](https://arxiv.org/abs/1805.00553)도 존재한다. 그러나 이번 조사에서는 즉시 쓸 상업 허용 가중치·족욕기 부분 촬영 성능을 확보하지 못했다. 따라서 ‘관련 연구가 없다’와 ‘바로 사용할 검증된 제품이 있다’ 사이를 구분한다.

## 4. 카메라에 대한 현재 결론

**‘생성하니 고가 카메라가 반드시 필요하지 않다’는 출발 가정은 타당하게 시험해 볼 수 있다. ‘그래서 카메라 성능은 중요하지 않다’고 확정하기는 이르다.**

브랜드 체험용 단일 이미지 생성이면 사진 품질 요구를 낮출 수 있다. 개인과 닮은 3D·회전 시 일관성·실제 크기 비교까지 원하면 입력 품질과 시야가 중요해진다. 해상도를 올려도 초점·가림·빛 반사 문제는 해결되지 않는다.

구매 전 확인할 항목은 실제 촬영 거리의 초점, 수동 노출/화이트밸런스·초점 고정 가능 여부, 카메라 여러 대 동시 연결, 입력 간 시점 겹침, 발바닥과 뒤꿈치의 가림이다. 가격·특정 모델·카메라 수는 이번에 확정하지 않았다.

수중 촬영은 별도 조건이다. [GEOMAR의 설명](https://www.geomar.de/en/cameracalibration)처럼 물·창 경계의 굴절은 3D 측정에 영향을 준다. [AquaCal](https://github.com/McGrathLab/AquaCal)은 참고 가능한 MIT 도구지만 평평한 수면을 보는 공기 중 카메라에 초점이 있어 족욕기의 모든 구조에 즉시 적용된다고 보지 않는다.

## 5. 구매 전에 비교할 작은 실험

이 항목은 제안이며 수행 결과가 아니다.

1. 동일한 발/하퇴의 건조 조건 사진 묶음을 확보한다. 먼저 휴대폰 사진으로 도구 적합성을 걸러낼 수 있다.
2. TripoSR, TRELLIS, 표준 해부학 자산 피팅을 각각 비교한다. 실제 다중 카메라 배열을 먼저 완성할 필요는 없다.
3. 발가락 개수·좌우·발목 연결·원본 유사성·회전 시 깨짐·내부 모델 정렬을 확인한다.
4. 같은 입력을 낮은 해상도로도 비교하고, 저가 카메라 실물 입력을 추가한다. 낮은 해상도 휴대폰 사진은 저가 렌즈·센서의 완전한 대용은 아니다.
5. 선정 경로에서만 고정 배열을 만들고 실제 입력 수·동시 연결·보정을 시험한다.
6. 물·창·스파 조명 환경을 넣어 실패율과 운영 시간을 비교한다.

모델별로 버전·가중치·입력 수·컴퓨터/GPU·VRAM·대기시간·성공/전체 수·수작업 수정시간을 남긴다. 공식 데모 속도와 현장 전체 처리시간은 구분한다.
