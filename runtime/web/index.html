시뮬레이션 안내
결과의 뼈와 근육은 일반 해부학 모형입니다. 사진 속 사람의 실제 내부나 초음파 검사 결과가 아니며 진단에 사용할 수 없습니다. 혈관은 표준 참조를 대략적으로 정렬하며, 지방은 일반적인 지방패드의 예시 위치입니다. 개인의 분포를 측정하지 않습니다.
01 · 입력

사진 선택

발끝이 오른쪽을 향하는 발 측면 사진을 사용하세요. 발 전체가 보이고 반사·가림이 적은 사진을 사용하세요. 발목 위쪽은 사진 밖으로 이어져도 됩니다. 일반 배경 분할은 실험 기능이며 수중 사진은 외형 분리 결과를 반드시 확인하세요.

합성 샘플은 실제 고객 사진이나 수중 촬영이 아닙니다.

02 · 진행 상황

처리 현황

사진을 선택하거나 샘플로 시작하세요.

외형 추출 → 표준 뼈·근육 정렬 → 사진과 모형 합성

사진은 이 컴퓨터에서만 처리됩니다. 현재 결과는 연구용이며 운영 현장에 적용하기 전에 추가 검증이 필요합니다.

03 · 결과표준 모형 기반 시뮬레이션

표준 내부 모형

촬영한 피부와 윤곽 안에 표준 모형을 겹쳐 보는 시뮬레이션입니다. 혈관 위치는 참조용이며 지방패드 위치는 측정값이 아닙니다.

발만 밝게 남아 있나요?

통 가장자리가 포함되거나 발 일부가 사라졌으면 다른 사진으로 다시 촬영해 주세요. 외형이 틀린 결과를 다음 단계로 넘기지 마세요.

3D 모델과 출처 다운로드이미지 크게 보기이미지 다운로드

체험은 어떠셨나요?

이미지가 자연스럽고 이해하기 쉬웠는지 알려 주세요. 답변은 이 기기에 저장됩니다.
